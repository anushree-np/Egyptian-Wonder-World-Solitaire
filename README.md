# Egyptian Wonder World Solitaire

An immersive Ancient Egyptian themed Klondike Solitaire game built using pure HTML, CSS, and Vanilla JavaScript.

This project transforms the classic Solitaire experience into a dark mystical Egyptian world featuring animated visuals, sound effects, timer mechanics, undo systems, and interactive gameplay — all without using any external libraries or frameworks.

---

## Features

- Fully playable Klondike Solitaire
- Ancient Egyptian dark theme
- Intro screen animation
- Responsive design
- Drag and drop card movement
- Undo and Undo All functionality
- 30-minute countdown timer
- No-more-moves detection popup
- Win celebration animation
- Golden particle effects
- Mild sound effects
- Mute / Unmute support
- Smooth lightweight animations
- Modular clean code structure

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

No external libraries, frameworks, CDNs, or packages were used.

## How to Run

1. Download or clone the repository
2. Extract the ZIP file if needed
3. Open `index.html` in any modern browser

No installation or setup required.

The game works fully offline.

---

## Gameplay

The game follows standard Klondike Solitaire rules:

- Arrange cards in descending order
- Alternate card colors
- Build foundation piles from Ace to King
- Complete all foundations to win
